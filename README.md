# Week 01 - Danny's Diner

## 📌 Case Study

Danny's Diner is a restaurant case study from the 8 Week SQL Challenge by Data With Danny.

The goal of this case study is to analyse customer purchasing behaviour, spending patterns, and the restaurant's loyalty program using SQL.

## 🛠️ SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- INNER JOIN
- Subqueries
- CASE WHEN
- Aggregate Functions
- COUNT()
- SUM()
- MIN()
- MAX()
- Window Functions
- DENSE_RANK()
- Date filtering
- INTERVAL

## 📊 Questions Solved

1. Total amount spent by each customer
2. Number of days each customer visited
3. First item purchased by each customer
4. Most purchased item overall
5. Most popular item for each customer
6. First purchase after becoming a member
7. Purchase just before becoming a member
8. Items and amount spent before membership
9. Customer loyalty points
10. Loyalty points earned at the end of January

## 📁 Files

- `dannys_diner.sql` - SQL solutions for all 10 questions

## 🎯 Key Learning

This case study helped me practise SQL joins, aggregations, subqueries, conditional logic, date functions, and window functions using a real-world business problem.
